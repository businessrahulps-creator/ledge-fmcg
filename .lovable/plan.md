## Goal

Replace the "print = browser print" model on /command with a real **Export to PDF** action that downloads a properly paginated, branded PDF — same look & feel as our other reports (Midnight letterhead, page numbers, "Generated by Ledge" footer). Browser print stays as a fallback.

## Why not just rely on `window.print()`

Even after the scroll/print CSS fixes, `window.print()` still depends on browser print settings, page chrome, fonts, and CSS-paged-media support. It's fragile, looks like a screenshot of the website, and users on mobile (most of our audience) effectively have no print flow. We already ship `@react-pdf/renderer` with a full design system (`PdfStyles`, `PdfHeader`, `PdfFooter`, `ReportPdf`) — same engine that powers Invoice / Dealer Statement / Performance / Salesperson PDFs. We use that.

## Scope

In:
- New "Download PDF" button next to the existing `PrintButton` on /command
- New `CommandPdf` document using existing PDF primitives
- Sections: Letterhead → Period & Company → KPI grid → Signals list → Aging buckets → Pipeline funnel → Trend table → Top dealers / Top salespersons / Top products leaderboards → Credit-at-risk dealers
- Pagination handled by `@react-pdf/renderer` (`wrap`, `break`, footer page numbers already in `PdfFooter`)
- Filename: `command_<period>_<YYYY-MM-DD>.pdf`
- Respects current period (today/7d/30d/90d/ytd/custom), tab is ignored — the PDF is the full snapshot
- Accountant role: hides People/Products leaderboards (matches in-app permissions)
- Hooked into existing `P` keyboard shortcut → triggers Export PDF (not browser print)
- Keep existing `PrintButton` as a secondary "Print page" option for users who still want the browser flow

Out:
- Charts as rasterized images (we render data as compact tables — same approach as `PerformanceReportPdf`)
- Section picker modal (`ExportPdfModal`) — Command snapshot is intentionally "all or nothing". Can add later if asked.
- Email delivery / scheduled digest
- Customizable templates

## Technical Approach

### Files to add

1. **`src/components/pdf/CommandPdf.tsx`** — `<Document>` with one or more `<Page size="A4">`
   - Reuses `PdfHeader`, `PdfFooter`, `pdfStyles`
   - Props: `companyName`, `companyAddress?`, `gstin?`, `logoUrl?`, `period` label, `range` (from/to), `revenue`, `kpis[]`, `signals[]`, `aging`, `pipeline`, `trend[]`, `topDealers[]`, `topSalespersons[]`, `topProducts[]`, `creditAtRisk[]`, `role`
   - Layout: letterhead → period summary box → summary cards (revenue, signals, aging totals) → signals table (priority + label + value) → aging strip as table → pipeline funnel as table → 12-week trend as table → leaderboards as 3 side-by-side tables with `wrap` → credit-at-risk table

2. **`src/components/pdf/buildCommandPdfData.ts`** — pure function that takes the same inputs `Command.tsx` already has (`orders`, `dealers`, `salespersons`, `targets`, `range`, `signals`, `companyInfo`) and returns the props object. Keeps `Command.tsx` thin and the data shape testable.

3. **`src/components/command/ExportPdfButton.tsx`** — small button using existing `downloadPdf` helper from `src/utils/exportPdf.ts`. Shows loading state via Lucide `Loader2`, toasts via Sonner (already wired in `downloadPdf`). Sits next to `PrintButton`.

### Files to edit

- **`src/pages/Command.tsx`**
  - Build the PDF data via `buildCommandPdfData(...)` (memoized)
  - Render `<ExportPdfButton data={pdfData} />` next to `<PrintButton />`
  - `useCommandShortcuts({ onPrint })`: change to trigger export PDF instead of `window.print()`; add a separate `Shift+P` (or move browser print to that) — keep simple: `P` = Export PDF, `Shift+P` = browser print
- **`src/components/command/KeyboardCheatSheet.tsx`** — update the `P` / `Shift+P` rows
- **`src/hooks/useCommandShortcuts.ts`** — add `onPrintBrowser` callback for `Shift+P`

### Data → PDF mapping (key bits)

```text
KPIs section:        Revenue, Orders, AOV, Collections, Outstanding, Credit at risk
Signals section:     priority badge + label + helper value, sorted high→low
Aging:               0-30 / 31-60 / 61-90 / 90+  (amount + dealer count)
Pipeline:            Quotation → Pending → Confirmed → Dispatched → Delivered counts + value
Trend:               last N buckets of dispatchedRevenue (period-dependent)
Leaderboards:        top 10 dealers (revenue), top 10 salespersons (revenue + target%), top 10 products (qty + revenue)
Credit-at-risk:      dealers with utilization ≥ 90%, sorted desc
```

All values formatted with existing `formatCurrencyPdf` ("Rs." prefix to stay Helvetica-safe — same convention as other PDFs).

### Pagination

`@react-pdf/renderer` handles A4 pagination natively. Each section is wrapped in a `<View wrap>` and tables use `<View wrap={false}>` per row (same pattern as `ReportPdf.tsx`). `PdfFooter` already renders "Page X of Y" + "Generated by Ledge · DD/MM/YYYY".

### Verification

1. Open /command on desktop + mobile → click "Download PDF" → file downloads named `command_30d_2026-05-19.pdf`
2. Open the PDF → letterhead correct, period correct, all sections present, multi-page, page numbers correct, no overlapping/clipped content
3. Switch period → re-export → values update
4. Accountant role → leaderboards section absent
5. `P` shortcut triggers download; `Shift+P` opens browser print dialog
6. Empty data state → renders "No data" rows instead of crashing
