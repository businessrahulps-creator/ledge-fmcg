

# PDF Export Feature — Implementation Plan

## Real User Needs

Indian FMCG distributors need PDFs for:
- **Order Invoice**: Print/WhatsApp to dealer after order capture (single order with line items, totals, company branding)
- **Orders Summary**: Daily/weekly batch of orders for accountant reconciliation
- **Stock Report**: Warehouse-wise inventory snapshot for godown manager
- **Dealer Statement**: Orders placed by a specific dealer over a period

## UX Design

### Button Placement
- **Single Order Invoice**: "Download PDF" button inside the Order Detail dialog (next to Save/Delete)
- **Orders List**: "Export PDF" button next to existing "Export CSV" button in the top action bar
- **Stock page**: "Export PDF" button next to existing CSV button (for warehouse inventory)
- **Reports tabs**: "Export PDF" button next to existing CSV button in each report tab

### PDF Options Modal
When clicking "Export PDF" on list pages, a modal appears with:
- **Title**: "Export PDF"
- **Sections to include** (checkboxes, all checked by default): varies per context
  - Orders: Summary stats, Order table, Payment breakdown
  - Stock/Warehouse: Summary stats, Inventory table, Health indicators
  - Reports: Summary stats, Detail table
- **Company header toggle**: Include company name/address/GSTIN header (on by default)
- **Generate button**: Creates and auto-downloads the PDF

For single order invoice, no modal — direct download (the invoice always includes everything).

### PDF Design (Black & White, A4)
- Company header: Name, address, GSTIN, phone — top-left, clean typography
- Document title + date generated — centered
- Tables with thin borders, alternating row shading (light gray #F5F5F5)
- All amounts right-aligned with ₹ Indian comma formatting
- All dates as DD/MM/YYYY
- Footer: "Generated by Ledge · {date} {time}" + page number
- No images/logos (keeps file tiny), pure text + tables

### File Naming
`{type}_{YYYY-MM-DD}.pdf` — e.g. `invoice_ORD-0042_2026-04-11.pdf`, `orders_2026-04-11.pdf`

## Technical Approach

### 1. Install `@react-pdf/renderer`
Only new dependency needed.

### 2. Create PDF Templates
- `src/components/pdf/PdfStyles.ts` — shared styles (fonts, table styles, header/footer)
- `src/components/pdf/OrderInvoicePdf.tsx` — single order invoice template
- `src/components/pdf/OrdersListPdf.tsx` — filtered orders summary
- `src/components/pdf/StockReportPdf.tsx` — warehouse inventory report
- `src/components/pdf/ReportPdf.tsx` — generic report template (used by all 5 report tabs)
- `src/components/pdf/PdfHeader.tsx` — reusable company header component
- `src/components/pdf/PdfFooter.tsx` — reusable page footer

### 3. Create Export Modal Component

### 4. Add PDF generation utility
