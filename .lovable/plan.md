

# Fix: Professional Invoice PDF with Scheme Details

## Problems Identified (from uploaded PDF)

1. **Scheme details missing** — Shows "Scheme Savings -Rs. 1,000" but no scheme name, type, or breakdown. The `order.appliedSchemes` array is available but never rendered.
2. **Layout feels sparse** — Order details are tiny boxes with excessive whitespace. The totals float right with no visual anchor. Only 30% of the page is used.
3. **No "Bill To" section** — Professional invoices have a clear billing section with dealer address.
4. **No visual separation** — Everything blends together without clear sectioning.

## Changes

### `src/components/pdf/OrderInvoicePdf.tsx` — Full redesign of body layout

**1. Two-column header info block:**
- Left: "Bill To" with dealer name (and address if available)
- Right: Invoice meta (Order #, Date, Salesperson, Payment status)
- Clean bordered layout like a real invoice

**2. Line items table** — Keep as-is (already good), just tighten padding.

**3. Totals section — right-aligned structured box:**
- Subtotal row
- If schemes applied: a "Schemes Applied" sub-section listing each scheme by name + savings
- Scheme Savings total row (green)
- Bold Effective Total row with a top border separator

**4. Dispatch section** — Keep as-is but only render if data exists.

### `src/components/pdf/PdfStyles.ts` — Add new styles

- `billToSection`, `invoiceMetaRow`, `totalsBox`, `schemeRow` styles for the professional layout.
